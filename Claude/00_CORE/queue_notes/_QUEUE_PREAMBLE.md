# How the queue works

⛔ **One queue: [`../QUEUE.md`](../QUEUE.md).** Never a second list.

**A row's status changes in TWO places or neither**: the one-line status in
`QUEUE.md`, and an append to this folder's `<ID>.md` dossier. The one-liner is what a
fresh session reads; the dossier is the full record — every measurement, retraction
and decision that produced the status.

⭐ **Append to a dossier, never rewrite it.** A claim that was overturned is more
useful than one silently deleted, and several in the predecessor were overturned
twice. Date every entry.

**The binding rule is `METHOD`'s first**: measure or revert. A row does not move to
✅ because the code exists; it moves when the measurement says so — and for anything
the user can feel, when a **look on a real device** says so.
